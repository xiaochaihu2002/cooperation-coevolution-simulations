## Cooperation on Adaptive Networks: Critical Selection Intensity

Simulation and visualization code for analyzing the critical selection intensity
$\beta^*$ in evolutionary game dynamics on adaptive networks.

### Overview

This project investigates how link breaking probabilities between cooperators (C)
and defectors (D) affect the critical selection intensity $\beta^*$—the threshold
below which cooperation cannot be favored and above which cooperation can be
favored.

#### Key Findings

| Figure | Description | Key Result |
|:---|:---|:---|
| Fig. 1 | Validation of second-order expansion | Theory captures ordinal relationship $\beta_1^* < \beta_2^*$ |
| Fig. 2 | Non-monotonic $\beta^*$ vs. $k_{CD}^*$ | Counter-intuitive increasing interval exists |
| Fig. 3 | Decoupled rationality: $\beta$ scan | Critical threshold persists without $\delta = a\beta$ |
| Fig. 4 | Decoupled rationality: $k_{CD}$ scan | Non-monotonic interval is intrinsic |
